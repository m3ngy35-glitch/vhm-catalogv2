📺 Send to stream overlay

Drag this button to the Chrome bookmarks bar on the staff laptop:

📺 VHM Overlay

  1. Open Vrich (Monitor page, or search a code on the Sale page).
  2. Click 📺 VHM Overlay in the bookmarks bar.
  3. Pick the code (if the page shows many), check the weight note, then tap Shirt / Pants / In hand.
  4. ✕ Clear removes a card. 🔄 Refresh updates the stock of every card on stream from this page.
  5. Text size / Smallest / Width and Cards ↔ Text change the overlay for everyone within a second.
  6. Opening 📺 VHM Overlay on the Vrich Sale page also starts 📣 Auto thank-you (badge bottom-left). Keep that tab open during the live. ⏹ on the badge stops it; the host screen switch hides pop-ups from the stream.

Cards whose sizes were typed by hand on the host screen (✋) are not changed by 🔄 Refresh, and a label typed on a card is kept. Use “↩ Use Vrich stock again” on the host screen to go back to real stock.

Your old Send stock bookmark still works as before. If you installed 📺 VHM Overlay before, drag this new one in and delete the old one.
